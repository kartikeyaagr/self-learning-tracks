A <strong>pipeline</strong> answers &quot;how was the model made from it?&quot;: which scripts ran, in which order, with which parameters. With DVC pipelines, one command rebuilds everything, and only re-runs the steps whose inputs changed. Pushing the results to S3 lets anyone reproduce or reuse them.</p>\n<h3>The idea in plain words</h3>\n<ul>\n<li>A <code>dvc.yaml</code> file lists <strong>stages</strong>. Each stage has a command, its <strong>dependencies</strong> (scripts, data, parameters) and its <strong>outputs</strong>.</li>\n<li><code>dvc repro</code> runs the stages in order. It hashes every dependency; if nothing a stage depends on changed, the stage is <strong>skipped</strong> and its cached output reused.</li>\n<li><code>params.yaml</code> holds the hyper-parameters; <code>dvc params diff</code> and <code>dvc metrics diff</code> compare them between commits.</li>\n<li>An S3 bucket is the remote where data, intermediate files and models are pushed.</li>\n</ul>\n<h3>Worked example: what re-runs</h3>\n<pre class=\"code\"><code class=\"language-yaml\">stages:\n  prepare:  {cmd: python src/prepare.py,  deps: [src/prepare.py, data/raw.csv],      outs: [data/clean.csv]}\n  features: {cmd: python src/features.py, deps: [src/features.py, data/clean.csv],    outs: [data/feats.parquet]}\n  train:    {cmd: python src/train.py,    deps: [src/train.py, data/feats.parquet], params: [train.lr, train.depth], outs: [model.pkl]}\n  evaluate: {cmd: python src/eval.py,     deps: [src/eval.py, model.pkl],            metrics: [metrics.json]}\n</code></pre>\n<div class=\"tbl\"><table>\n<thead>\n<tr>\n<th>You change</th>\n<th>Stages that re-run</th>\n</tr>\n</thead>\n<tbody><tr>\n<td><code>train.lr</code> in params.yaml</td>\n<td>train, evaluate</td>\n</tr>\n<tr>\n<td><code>src/features.py</code></td>\n<td>features, train, evaluate</td>\n</tr>\n<tr>\n<td><code>data/raw.csv</code></td>\n<td>all four</td>\n</tr>\n<tr>\n<td>nothing</td>\n<td>none (&quot;Data and pipelines are up to date.&quot;)</td>\n</tr>\n</tbody></table></div>\n<p>If preparing takes 20 minutes and training 5, a learning-rate change costs 5 minutes plus evaluation, not 25.</p>\n<figure class=\"dg viz\" data-viz=\"dockerlayers\" data-p=\"{}\"><div class=\"vz\"></div><figcaption>The same principle in Docker: a step is rebuilt only if its inputs changed, and so is everything after it.
