question: "<code>torch.tensor(np_array)</code> and <code>torch.from_numpy(np_array)</code> both work. You modify the NumPy array afterwards. Which tensor changes, and which choice is right for a data loader?"
answer: "<code>from_numpy</code> shares memory, so it changes; <code>torch.tensor</code> copies, so it does not. In a data loader, <code>from_numpy</code> avoids a copy, but make sure the array is not reused or mutated later (and that its dtype is what the model expects, e.g. float32 not float64)."
