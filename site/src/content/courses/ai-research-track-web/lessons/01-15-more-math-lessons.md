question: "Why do 4-bit quantised LLM weights need a separate scale per small group (e.g. 64 weights), rather than one scale per tensor?"
answer: "4 bits give only 16 levels. One outlier weight in a tensor sets the scale for all, so most weights round to the same few levels. Per-group scales let each group use its own range, at the cost of storing one scale (often float16) per group, about 0.25 extra bits per weight for groups of 64."
