title: "Train LLM — Sequence Length vs Batch Size"
question: "At a fixed number of tokens per batch, you double the sequence length and halve the batch size. How do compute per token and gradient noise change?"
answer: "Attention&#39;s score computation per token roughly doubles, because it scales with sequence length; MLP and projection compute per token is unchanged. Gradient noise depends mainly on tokens per batch, which is unchanged, though tokens within one sequence are correlated, so the effective batch is slightly smaller. The gain is learning longer-range dependencies."
