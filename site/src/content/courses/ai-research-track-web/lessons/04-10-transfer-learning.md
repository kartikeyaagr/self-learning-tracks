question: "You cache frozen-backbone features once, then add random flips and crops to the training images to fight overfitting. Accuracy does not change. Why?"
answer: "The cached features were computed from un-augmented images, so the head never sees the augmentation. With augmentation, run the frozen backbone inside the training loop (or cache several augmented copies)."
