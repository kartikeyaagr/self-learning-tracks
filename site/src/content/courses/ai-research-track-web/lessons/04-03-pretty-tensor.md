question: "Old TF1 code calls <code>sess.run(train_op, feed_dict={x: batch})</code>. Translate this into TF2 in words, and say why <code>print(loss)</code> inside the TF1 model showed no number."
answer: "In TF2, the training step is a normal Python function (optionally <code>@tf.function</code>) called with the batch as an argument; there is no session or placeholder. In TF1, model code only built a graph, so <code>print</code> showed a symbolic <code>Tensor</code>; values existed only when <code>sess.run</code> executed it."
