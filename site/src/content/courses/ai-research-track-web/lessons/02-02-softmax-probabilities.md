With <code>dim=0</code> each class column sums to 1 across the batch, which is meaningless.</li>\n<li><strong>Applying softmax before <code>F.cross_entropy</code>.</strong> That loss expects logits and applies <code>log_softmax</code> itself.</li>\n<li><strong>Writing <code>exp(z) / exp(z).sum()</code> by hand.</strong> It overflows for large logits. Use <code>torch.softmax</code> or <code>log_softmax</code>.</li>\n<li><strong>Reading softmax outputs as calibrated confidence.</strong> A model can say 0.99 and still be wrong often. Calibration is a separate question.</li>\n</ul>\n<h3>Try it yourself</h3>\n<ol>\n<li>Logits <span class=\"katex\"><span class=\"katex-html\" aria-hidden=\"true\"><span class=\"katex-base\"><span class=\"katex-strut\" style=\"height:1em;vertical-align:-0.25em;\"></span><span class=\"mopen\">(</span><span class=\"mord\">0</span><span class=\"mpunct\">,</span><span class=\"mspace\" style=\"margin-right:0.1667em;\"></span><span class=\"mord\">0</span><span class=\"mpunct\">,</span><span class=\"mspace\" style=\"margin-right:0.1667em;\"></span><span class=\"mord\">0</span><span class=\"mpunct\">,</span><span class=\"mspace\" style=\"margin-right:0.1667em;\"></span><span class=\"mord\">0</span><span class=\"mclose\">)</span></span></span></span>.
