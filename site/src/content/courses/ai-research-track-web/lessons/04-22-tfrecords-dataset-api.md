The guide&#39;s main recommendations:</p>\n<ul>\n<li><code>.map(fn, num_parallel_calls=tf.data.AUTOTUNE)</code> parallelises preprocessing.</li>\n<li><code>.prefetch(tf.data.AUTOTUNE)</code> at the end overlaps preparing the next batch with training on the current one.</li>\n<li><code>.cache()</code> after expensive, deterministic steps; before random augmentation.</li>\n<li><code>.shuffle(buffer)</code> before <code>.batch</code>; a buffer smaller than the dataset gives only partial shuffling.</li>\n<li><strong>TFRecord</strong> files store serialised <code>tf.train.Example</code> protos sequentially, which reads fast from disk and cloud storage.
