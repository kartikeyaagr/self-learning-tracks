question: "After <code>kubectl apply</code>, pods are Running but requests fail for 30 seconds after each restart. What is missing?"
answer: "A readiness probe. Without it, Kubernetes sends traffic as soon as the container starts, before the model has loaded. Add a readiness probe on <code>/health</code> that returns success only once the model is ready."
