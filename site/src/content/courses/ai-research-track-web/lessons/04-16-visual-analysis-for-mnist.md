Maximising &quot;0&quot; gives ring-like curves. The pictures are recognisable but not clean digits: the network only needs the features it uses to discriminate, not everything a human would draw.</p>\n<figure class=\"dg viz\" data-viz=\"actmax\" data-p=\"{}\"><div class=\"vz\"></div><figcaption>The same gradient ascent as lesson 04.15. Methods like integrated gradients address this.</li>\n<li><strong>Trusting noisy maps.</strong> Gradients of ReLU networks are noisy. SmoothGrad averages saliency over several slightly noisy copies of the image.</li>\n<li><strong>Sanity checks skipped.</strong> Adebayo et al. (2018) showed some saliency methods produce similar maps even for a network with random weights. Always compare with a randomised network.</li>\n</ul>\n<h3>Try it yourself</h3>\n<ol>\n<li>For the linear model, why is the saliency map the same for every image?</li>\n<li>Saliency for a ReLU network is zero at a pixel.
