question: "After <code>x = x.transpose(1, 2)</code>, <code>x.view(B, -1)</code> raises an error but <code>x.reshape(B, -1)</code> works. Why, and what does reshape do differently?"
answer: "Transpose only changes strides, so the tensor is no longer contiguous in memory, and <code>view</code> cannot reinterpret it without copying. <code>reshape</code> returns a view when possible and otherwise copies (as <code>x.contiguous().view(...)</code> would).
